Run the Monday-morning standup of Claude, Inc. on the current working directory. Optional focus: $ARGUMENTS

1. Skim the project first: README, file structure, anything recently changed.
2. Launch all 8 department agents in parallel via the Task tool. Each VP returns **at most 4 bullets**: 2 observations, 1 opportunity, 1 recommended next action — strictly within its domain.
3. Compile the **Standup Board**: one row per department (Department | Status | Opportunity | Next action).
4. Close with **CEO's pick**: the single highest-leverage action for today, and why.

Keep it tight. A standup that takes longer than the work is a fired standup.
