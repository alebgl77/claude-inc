# Visual assets

The company has peer CEO, CTO and CAIO executives, nine departments with six
manuals each, and ten staff manuals: 64 specialist skills in total. Keep that
roster consistent across the diagrams, illustrations, and sharing cards.

| Asset | Purpose | Source and maintenance |
| --- | --- | --- |
| `assets/banner.png` | README robot company illustration | Manually edited with image generation; preserve the existing robot style and show all three peer executives and nine departments. |
| `studio/company-team.png` | Matching robot company illustration distributed with the site | Keep synchronized with `assets/banner.png`; this bitmap is not generated by the company builder. |
| `assets/org-chart.svg`, `studio/org-chart.svg` | Detailed organization map, 1440 × 1110 | Identical copies generated from canonical charters and skill manuals by `scripts/build_company.py`; names every manual once. |
| `studio/company-preview.svg` | Compact organization map in the home-page hero, 1200 × 630 | Generated by the same company builder. |
| `studio/social-preview.svg` | Editable social-card source, 1200 × 630 | Generated by the company builder, using the canonical roster and totals. |
| `studio/social-preview.png` | Open Graph and Twitter image for both site pages, 1200 × 630 | Export the generated social SVG using the command below. |
| `studio/favicon.svg` | Site icon | Existing vector brand mark. |

The SVG social card preserves the warm paper, ink and orange palette, Georgia
headline, sans-serif body, Consolas labels, fine rules, and two-column editorial
composition. Raster illustrations are reviewed separately; regenerating the
directory does not update their pixels.

## Regenerate and check the vector sources

From the repository root:

```sh
python -B scripts/build_company.py
python -B scripts/build_company.py --check
```

The check is read-only and covers the directory data, both detailed map copies,
the compact map, and the social SVG. It does not render or compare PNG pixels.

## Optional PNG export

With Node and Sharp already available, export the new SVG directly. No renderer
is needed by the website, Python builder, or Pages deployment, and no project
dependency needs to be installed. In PowerShell on the bundled Codex runtime:

```powershell
$visualRuntime = Join-Path $env:USERPROFILE '.cache/codex-runtimes/codex-primary-runtime/dependencies/node'
$visualSharp = Join-Path $visualRuntime 'node_modules/sharp'
@'
const sharp = require(process.argv[2]);
sharp("studio/social-preview.svg").png().toFile("studio/social-preview.png")
  .then(info => console.log(info))
  .catch(error => { console.error(error); process.exitCode = 1; });
'@ | & (Join-Path $visualRuntime 'bin/node.exe') - $visualSharp
```

Use the same Sharp version and installed Georgia, Trebuchet MS and Consolas
fonts to reproduce the same raster rendering. Inspect the resulting PNG for
legible CEO, CTO, CAIO and all nine department labels; confirm 1200 × 630 pixels.

## Publication checks

```sh
python -B -m unittest discover -s tests -p test_company_builder.py
node --test tests/test_company.js tests/test_studio.js
```

The Pages workflow explicitly stages public files. Its tests stage that same
allowlist and verify every local HTML link, image, script, stylesheet and social
image resolves, then compare the social metadata with the PNG dimensions. Keep
both `company-preview.svg` and the social SVG/PNG in the public asset list.
