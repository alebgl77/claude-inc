# Draft Outreach — Cold Emailer

> "Earn the reply, don't trick it."

## When to use

- "Write a cold email to {prospect}"
- "Draft outreach for this account"
- "Follow up, they never answered"
- Right after `account-research` — never write outreach to a stranger you haven't researched
- LinkedIn DMs, X DMs and short-form intros included

## Workflow

1. **Load the account brief** (or run a quick research pass if none exists — no brief, no outreach).
2. **Pick the angle**: one observed signal → one pain → one credible promise. One. Multi-pain emails read like spam.
3. **Draft the first touch**: ≤ 90 words. Line 1 proves you did homework (specific, non-creepy). Line 2-3 connect pain → outcome with proof. Close with a low-friction CTA (question or 15-min ask), never "let me know your availability for a quick sync".
4. **Write 3 subject lines**: 2-4 words, lowercase-friendly, zero clickbait. No "Re:", no fake forwards, ever.
5. **Build the follow-up ladder**: +3 days (new value: insight/resource), +7 days (different angle or social proof), +14 days (graceful breakup that leaves the door open). Each ≤ 60 words, none saying "just bumping this".
6. **Personal-ify**: adapt to the user's voice profile if one exists (`voice-builder` output); default to plain, human, contraction-friendly prose.
7. **Compliance pass**: no false claims, honour opt-outs, one-click identifiable sender. Flag anything Legal should see.

## Output format

```
## Outreach kit — {prospect}
Angle: {signal} → {pain} → {promise}

**Subject options**: 1. ... 2. ... 3. ...
**Email 1 (day 0, ≤90w)**: ...
**Email 2 (day 3, ≤60w)**: ...
**Email 3 (day 7, ≤60w)**: ...
**Email 4 (day 14, breakup)**: ...
**DM variant (≤300 chars)**: ...
Send window: {day/time + rationale}
```

## Quality bar

- [ ] First line is specific to THIS prospect (passes the "could this be sent to anyone else?" test — answer must be no)
- [ ] ≤ 90 words for touch 1; zero jargon; reads aloud naturally
- [ ] Exactly one CTA per message
- [ ] No deceptive subjects, no fake familiarity, no guilt-tripping follow-ups
- [ ] Sequence provides new value at every touch

## Example

**Ask**: "Cold email to the CTO of a startup that just migrated to PrestaShop 9, I sell SEO rescue."
**Produced**: subject "category pages 404" · touch 1 citing two live broken URLs, one promise (recover pre-migration rankings in 30 days), CTA "worth 15 minutes?", plus 3 follow-ups ending in a clean breakup.
