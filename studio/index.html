02 / HOW THE COMPANY WORKS

A project, with
a working organization.

Give the company context once. Return to the same project as the work develops.

  1. 01

    You bring the project.

    An existing codebase, a business, a new product, or a problem worth solving. Set the goal and constraints.

  2. 02

    The CEO scopes the work.

    Clarify what done means. Assign department owners, split tasks, and record dependencies in the project board.

  3. 03

    Departments deliver.

    The department heads use their employee manuals. Work produces files, decisions, and explicit handoffs.

  4. 04

    Review. Decide. Continue.

    Review the evidence. Record results and blockers locally, then pick up from the project’s saved state.

    04 / MAKE IT YOUR COMPANY

    Bring something
    you want to build.

    Start with your own project, at any stage. The entire company is available; your brief gives it a direction.

    1. Install the company.

      Install the CLI and company files using the repository instructions. You’ll need Claude Code and Python 3.9+ locally.

      Open installation instructions ↗

    2. Download your project brief.

      Use the form here. Put company-brief.md in the project folder where you want the company to work.

    3. Initialize, then start.

      In a terminal inside that project folder:

      company project init --name 'My project' --brief-file company-brief.md
company project start

      Replace the fixed sample name in your terminal if you want. Start opens a local Claude Code session with the company and saved project context.
